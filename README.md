# Bank słówek — angielski

Aplikacja do nauki słownictwa z działu **13. Słownik tematyczny**: pogoda i klimat, zagrożenia i ochrona środowiska, katastrofy ekologiczne. 79 słówek z podręcznika (MP3 108, 111, 113).

**Strona:** https://inowara.github.io/bank-slowek/

## Funkcje

- **Nauka** — wpisujesz tłumaczenie (Enter), sprawdzanie odporne na wielkość liter, nadmiarowe spacje i polskie znaki (`mrozny` = `mroźny`)
- **Fiszki** — obracanie karty, oceny „Znam” / „Nie znam”, nieznane słówka wracają na koniec talii
- **Słówka** — cały bank z wyszukiwarką
- Przełącznik kierunku **PL → EN / EN → PL** i filtry kategorii
- Motyw jasny/ciemny, postęp zapisywany w `localStorage`

## Uruchomienie

Plik `index.html` jest samodzielny — wystarczy otworzyć go w przeglądarce. Bez builda, bez zależności.

Źródło słownictwa: `bank slowek.png`.
